> [!NOTE]
> 3 Sum is just a complicated version of two sum
> Consists of two main parts
>  1) Find new target for every value 
>  2) Perform two sum on the other elements with the new target value
> 
> - Sort in order to get duplicates next to each other 
>   - Easier to do it this way so we don't have to create any extra overhead w/ dsa
